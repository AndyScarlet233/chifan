# 中国人怎么吃饭

> 一份写给朋友的小册子：关于中国人餐桌上那些"没人明说、但人人都在遵守"的规矩。

---

## 一、开席之前，座次就是秩序

中餐的餐桌不是均匀的，它自带一套坐标系统。

- **面门为尊**：正对房门的位置留给主人或主宾——因为坐在那里的人最先看见客人进门，也最先被看见。
- **左为上，右为次**：主宾坐主人左手边，二宾坐右手边，以此类推向外摊开。
- **末座最辛苦**：背对门、离茶水壶最近的位置，传统上由主人自己坐——上菜、倒茶、张罗，都是末座的活。

所以中国人入席前总有一番"你坐你坐"的推让：不是客气，是大家在**用身体排一张看不见的组织结构图**。

## 二、筷子上的规矩

一双筷子两根棍，规矩比手术刀还多。最常被长辈敲手背的几条：

| 禁忌 | 为什么 |
|---|---|
| 不把筷子插在饭上 | 形似上香，是祭祖的形状 |
| 不用筷子敲碗沿 | 旧时乞讨者敲碗要食 |
| 不用筷子指人 | 筷子是手的延伸，指筷等于指人鼻子 |
| 不在盘里翻拣 | "迷箸刨坟"——只夹眼前那一块 |
| 不含着筷子说话 | 像叼着武器讲话 |
| 夹菜不过河 | 只夹自己面前的区域，别横跨转盘 |

还有一条最日常的：**给别人夹菜要用公筷**。这条在近几年从"讲究"变成了"常识"。

## 三、转盘的礼仪：一张桌子的红绿灯

圆桌中间那个玻璃转盘，是中国人发明的最优雅的公共资源分配装置。它的交通规则：

1. **顺时针转**，方向定了就别逆行。
2. 转盘是**公共的**——别人正在夹菜时，你的手要停。
3. **新菜先转到主宾面前**，再慢慢转回来。
4. 想吃远处的菜，**等转盘经过时出手**，不伸手去够——够不着，说明还没轮到你。

一句话总结：转盘上没有个人的食欲，只有全桌的节奏。

## 四、点菜是一门隐学

中国人点菜，点的不是菜，是**局面**：

- **菜数取双**：六、八、十道，"四"要避开（谐音不吉）；
- **冷热荤素搭配**：冷盘开胃、热菜扛旗、一汤收尾；
- **有饭有面**：北方饭局最后可以有面点，南方讲究"主食不上桌"则相反；
- **人数减一是常量**：八人点七道菜再加一个汤，几乎是公式。

会点菜的人，往往就是这桌饭真正的主人。

## 五、喝酒的分寸

中国酒桌的核心不是喝，是**敬**：

- 敬酒按身份顺序来，先主宾后主人，先长辈后平辈；
- **碰杯时杯沿低于对方**——把自己的姿态放低半寸，敬意就到了；
- "我干了您随意"是给对方台阶，也是给自己留量；
- 不能喝，提前说，落座第一句就声明，比喝到一半推杯体面得多。

酒是媒介，话才是菜。

## 六、八大菜系，一口记住

| 菜系 | 一句话 |
|---|---|
| 鲁 | 官府菜的底子，葱烧与奶汤 |
| 川 | 一菜一格，百菜百味，麻辣只是门面 |
| 粤 | 清鲜为本，"不时不食" |
| 苏 | 浓中带淡，甜出头咸收口 |
| 浙 | 湖山清味，讲究本味 |
| 闽 | 一汤十变，红糟入馔 |
| 湘 | 香辣厚重，腊味当家 |
| 徽 | 重油重色，火功见长 |

北方朋友别急：北京烤鸭、东北乱炖、西北面食，不在八大之列，但一样是正经江湖。

## 七、一个人也要好好吃饭

过去中国人的餐桌至少两张脸：家里的圆桌和饭馆的大桌。如今多了第三种——**一个人的一人食**。

外卖备注里写"不要辣、多加饭"，便利店的关东煮，深夜的一碗泡面加蛋——**一人食不是将就，是中国人吃饭方式里最新的一条支流**。老规矩管不了外卖订单，但"热菜热饭、按时吃"这条底线，每个中国人都还守着。

## 八、年夜饭：所有规矩的总和

一年里最隆重的一顿饭，把上面所有规矩都用上了：座次排到最满，菜数取到最多，鱼一定要有（年年有余），饺子一定要包（更岁交子），长者先动筷，晚辈才开吃。

**中国人怎么吃饭？——在饭桌上认亲，在筷子间论礼，在举杯时把想说没说的话都说完。**
